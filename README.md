# Словешки · 1.0.0-beta.2

Командная игра на одном телефоне. Открывается по ссылке в мобильном браузере и в Telegram Mini App. Все слова, шрифты, изображения, звуки и Phaser входят в сборку.

## Как разместить игру

1. Распакуй ZIP. Загрузи содержимое в корень ветки main своего репозитория GitHub. Файл index.html должен лежать рядом с папками assets, src и vendor.
2. В Settings → Pages выбери Deploy from a branch, затем main и /(root). Нажми Save.
3. После публикации открой Visit site. Скопируй этот HTTPS-адрес в настройки Mini App своего бота. Ссылка для репозитория проекта обычно выглядит как https://ИМЯ.github.io/РЕПОЗИТОРИЙ/.
4. Открой игру через бота на телефоне. После касания «Начать» проведи по слову вверх и вниз. Проверь звук, паузу и возврат в игру после сворачивания Telegram.

Для локальной проверки выполни python3 -m http.server 8000 в папке с index.html и открой http://localhost:8000.

## Как играть

Передавайте телефон между командами. Объясняйте слово описанием, примерами, синонимами и жестами. Само слово и однокоренные подсказки запрещены. Свайп вверх засчитывает ответ, вниз пропускает слово. Последнее слово остаётся после сигнала до ответа команды. После хода нажмите на звезду для исправления и подтвердите результат. Когда достигнута цель, команды завершают круг. Побеждает команда с наибольшим счётом, равный лучший счёт даёт ничью.

Три набора по 1000 записей. По умолчанию ход длится 30 секунд, цель — 30 очков. За пропуск начисляется 0, в настройках можно включить вычитание 1 очка. Незаконченная игра сохраняется в том браузере или Telegram, где её начали.

В beta.2 параметры экрана и звука доступны в главном меню → Настройки. Громкость сохраняется на устройстве. Новые игры используют словарь v2. Если продолжить игру из beta.1 по прежнему адресу сайта, сохраняются её слова и счёт.
